# 2025-W50週次レポート（12/08〜12/14）

## キャッチアップ（AI）

2.0.62
2025年12月9日

- 複数選択式の質問で推奨される選択肢に`(Recommended)`を表示し、推奨項目をリストの先頭に移動
- コミットやPRのbylineをカスタマイズできる`attribution`設定を追加（`includeCoAuthoredBy`の後継）
  - `settings.json`の`attribution`で設定できる
- `/install-slack-app`コマンドを追加
- Claude for Chrome拡張機能のインストール状況を検出できるようになった
- プラグインをユーザー・プロジェクト・ローカルのスコープを指定してインストールできるようになった
- セッション履歴検索で、タイトルや要約だけでなくメッセージ本文もファジー検索できるようになった
- プラグインブラウザにページネーションとスクロールインジケーターを追加
- プラグインのエラーメッセージをエラー種別ごとに分類し、対処方法を表示するようになった
- Plan Modeで、複雑なタスクでは事前に計画することをより積極的に推奨するよう`EnterPlanMode`のガイダンスを強化
- macOSのSandboxでPTY操作を許可する`allowPty`設定を追加
  - PTY = Pseudo Terminal
  - `ls`などとは異なり、`npm run dev`は対話形式だが、これの実行を`allowPty`で許可することで、Sandbox内での対話形式の操作が可能になる
- Sandboxから`.git/config`へのアクセスを制御する`allowGitConfig`設定を追加
  - originやremoteなどの情報を管理するファイル
- 設定の読み込み元を追跡する`flagSettings`スコープを追加

2.0.64
2025年12月10日

- 自動コンパクションを即時実行するようになった
- AgentとBashコマンドを非同期実行できるようになり、完了時にメインエージェントへメッセージを送信できるようになった
- `/stats`でお気に入りのモデル、使用量グラフ、利用ストリークなどの統計情報を確認できるようになった
- `/rename`でセッションに名前を付け、名前を指定してセッションを再開できるようになった
- `.claude/rules/`をサポート
- 画像のリサイズ時に画像サイズのメタデータを追加し、大きな画像でも正確な座標マッピングができるようになった
- `/resume`画面でフォークされたセッションをグループ化し、プレビューや名前変更のキーボードショートカットに対応
- VS Code拡張でコードブロックやBashツール入力をクリップボードへコピーするボタンを追加
- Bedrockでトークンカウントの効率を改善
- Bedrockで`aws login`によるAWS Management Console認証情報をサポート
- `AgentOutputTool`と`BashOutputTool`を廃止し、統合された`TaskOutputTool`へ移行
  - 設定の出所を追跡できる
  - 設定がうまく変更できない際にどの設定ソースが影響しているかを確認できる

2.0.65
2025年12月11日

- `Alt+P`（Linux/Windows）または`Option+P`（macOS）でプロンプト入力中にモデルを切り替えられるようになった
  　- 今まで毎回止まるまで待っていたので助かる
- ステータスラインにコンテキストウィンドウ情報を表示
- カスタムの`@`ファイル検索コマンドを設定できる`fileSuggestion`設定を追加
- `CLAUDE_CODE_SHELL`環境変数で使用するシェルを明示的に指定できるようになった
- `/tag`コマンドでセッションに検索可能なタグを付けられるようになった
  - セッションを見つけられないことがたまにあるが、それを回避できる
- `TaskOutput`ツールを追加し、バックグラウンドShell・Agent・リモートセッションの出力取得を統一
  - Shell, Agent, Remoteの結果出力の仕組みは今までバラバラだったが、統一された
- MCPツールの遅延ロード（Deferred Loading）に対応
- Git worktreeを検出できるようになった
- エンタープライズ向けリモート設定同期の基盤を追加
- LSPの位置指定を1始まりの行・文字位置に変更
  - LSP（Language Server Protocol）
  - 1始まりにすることにより、VS Codeなどのエディタと互換性を持たせた
- 現在適用されている設定ソースを表示できるようになった
- プラグインのインストール状況を追跡する仕組みを追加
- セッションをタグで検索できるようになった
- `DISABLE_COMPACT`環境変数で自動コンパクションを無効化できるようになった
- MCPツールを動的に検索するMCP Tool Searchに対応

- Unicodeの単語境界を利用したテキスト入力の単語移動に対応
