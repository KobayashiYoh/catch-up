## 学んだこと

- Claude Code for Desktopを使うとGUI操作でClaude Codeを利用できる
- Bashコマンドで`$!`を使うと、直前にバックグラウンド実行したプロセスのPID（プロセスID）を確認できる
- PIDはOS上でプログラムごとにわりあてられる
- PIDがわかると、killなどで特定のプロセスを狙い撃ちで終了させることができる
