# 2025-W42週次レポート（10/13〜10/19）

## キャッチアップ（AI）

- モデルセレクターに Haiku 4.5 を追加
- Haiku 4.5 はプランモードで自動的に Sonnet
  を使用し、実行には Haiku を使用（デフォルトは
  SonnetPlan）
  - サードパーティ（Bedrock・Vertex）は自動アッ
    プグレードされない。ANTHROPIC_DEFAULT_HAIKU_MODE
    L 設定で手動アップグレード可能
- Explore サブエージェントを導入。Haiku
  を搭載し、コンテキストを節約するためにコードベー
  スを効率的に検索する
- 長時間実行の bash コマンドを強制終了せず自動で
  バックグラウンド化。BASH_DEFAULT_TIMEOUT_MS
  でカスタマイズ可能
- Skillのサポートを追加
- ツールレスポンスの MCP structuredContent
  フィールドをサポート
  - 従来はAIのみが理解可能なテキストが返されたいた
  - structuredContentはAIと人間が両者理解可能な構造化されたJSONレスポンスを返すためのフィールド
- インタラクティブな質問ツールを追加
  - Claudeがユーザーに向けて質問を投げかけることができるようになった
- プランモードで Claude
  がより頻繁に質問するようになった
 - IDE: thinking
  の有効/無効を切り替えるトグルを追加
  - thinking ONは内部推論で複雑なコードに適しており、OFFは単純なコードに適している
  - エンタープライズ向けのマネージド MCP
  許可リスト・拒否リストをサポート
    - 個別にリポジトリで設定ではなく、組織で一括設定

## キャッチアップ（モバイルアプリ開発）

- Flutter3.35.0リリースノート
  - https://blog.flutter.dev/whats-new-in-flutter-3-35-c58ef72e3766
  - WebにてStateful Hot Reloadが有効化
    - ステートレスホットリロードとは、状態をリセットしてホットリロードを行うこと
    - ステートフルホットリロードとは、状態を保持したままホットリロードを行うこと
  - Wasm ドライランの導入
    - FlutterのビルドにはJSビルドとWasmビルドがあり、Wasmビルドの方が高速
    - 将来的にはWasmビルドがデフォルトになる予定
    - ドライラン導入により、互換性をあらかじめチェックできるようになった
  - アクセシビリティの強化（SemanticsLabelBuilder・SliverEnsureSemantics追加、RTL対応改善）
  - 新コンポーネントの追加（DropdownMenuFormField・スクロール可能なNavigationRail・CupertinoExpansionTile等）
  - CupertinoウィジェットにRSuperellipse形状と触覚フィードバックを追加
  - Material/Cupertinoライブラリをコアフレームワークから分離する計画を開始（現時点で影響なし）
  - Dart & Flutter MCPサーバーの安定版
    - Dart・Flutterのエラーに対して自己修復を行う
    - ツールチェーンとは、flutter, dart, analyzer, pubなどのコマンドの総称
    - ランタイムエラーの修正ができる（例：RenderFlexオーバーフローの自動修正ができる）
    - ボイラープレート（定形コード）の生成
  - Widget Previews（実験的）
  - dart analyze等の高速化（AOTコンパイル済みスナップショット採用により最大約50%高速化）
  - JetBrains Flutterプラグインv M87 — CLion・GoLand・PyCharmなど追加サポート
    - JetBrainsのIDEでFlutter開発が可能になる
    - アプリ起動時間短縮
  - Android最低SDKがAPI 24（Android 7）に引き上げ
    - flutter.minSdkVersion を 24 以上に設定し直す必要がある
  - iOSのLive Text（OCR）復活
    - Live Textとは、iOSにて画像内のテキストを認識してコピーできる機能のこと
  - Display P3カラー修正（macOS）
    - 色域（色の表現範囲）の規格の一つであり、sRGB（一般的な標準）よりも広い色域を持つ
  - Radioウィジェットが RadioGroup ベースに再設計
  - コンポーネントテーマの正規化完了（AppBarThemeなど）
  - Android 32bit x86アーキテクチャが非推奨
    - アーキテクチャ=CPUの種類
    - 32bit x86は古いCPUアーキテクチャであり、主に古いエミュレータで使用されている
  - Gradle 8.7 / AGP 8.6 / Java 17 が最低要件に
    - GradleはAndroid以外でも使われる汎用ツールであり、AGPはそれをAndroidアプリビルド用に拡張したもの
    - コマンドラインで対応可能
