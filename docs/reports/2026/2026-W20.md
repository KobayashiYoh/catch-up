# 2026-W20週次レポート（05/11〜05/17）

## キャッチアップ（AI）

- ルートレベルに SKILL.md があり `skills/` サブディレクトリのないプラグインがスキルとして表示されるようになった
- Fast モードのデフォルトが Opus 4.7 になった（以前は Opus 4.6）。`CLAUDE_CODE_OPUS_4_6_FAST_MODE_OVERRIDE=1` で Opus 4.6 に固定可能
- `CLAUDE_CODE_PLUGIN_PREFER_HTTPS` を追加。SSH キーのない環境で GitHub プラグインソースを SSH の代わりに HTTPS でクローンできる
- オートモードの権限ダイアログが `permissions.ask` ルールによって起動した際に説明を表示するようになった
- `/goal` コマンド: 完了条件を設定するとその条件が満たされるまで Claude がターンをまたいで作業を継続。インタラクティブ・`-p`・Remote Control で動作。経過時間/ターン数/トークン数をオーバーレイパネルでリアルタイム表示
- `/scroll-speed` コマンド: ライブプレビュー付きでマウスホイールスクロール速度を調整
- `claude plugin details <name>`: プラグインのコンポーネント一覧と予測セッションあたりトークンコストを表示
- `claude plugin install <name>@<marketplace>` がプラグイン未検出と報告する前にマーケットプレイスを自動更新してリトライするようになった
- サブエージェントからの API リクエストに `x-claude-code-agent-id` / `x-claude-code-parent-agent-id` ヘッダーが付与されるようになった。`claude_code.llm_request` OTEL スパンに `agent_id`/`parent_agent_id` 属性を含む

## キャッチアップ（モバイルアプリ開発）

- 新規追加機能なし

## 学んだこと

- `CLAUDE_CODE_PLUGIN_PREFER_HTTPS`（SSHキーのない環境でGitHubプラグインソースをSSHの代わりにHTTPSでクローンする）は、正直使いたくないし、使って欲しくない
- オートモードの権限ダイアログが`permissions.ask`ルールによって起動した際に説明を表示するようになったことで、なぜ引っかかったのかを理由を説明してくれるようになった
- `claude plugin install <name>@<marketplace>`がマーケットプレイスを自動更新してリトライするようになったのは、チームでプラグインを共有している場合に便利そう
- サブエージェントからのAPIリクエストに`x-claude-code-agent-id` / `x-claude-code-parent-agent-id`ヘッダーが付与されるようになったことで、複数エージェントが動作している際、どのエージェントが誰の指示で動いているかを追跡できるようになった
- サブエージェントがAnthropic APIを呼ぶ時、自分のIDと親エージェントIDをリクエストヘッダーにつけるようになった
- OTELとはOpenTelemetry（分散トレーシングの標準規格）のこと
