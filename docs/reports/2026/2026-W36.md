# 2026-W36週次レポート（08/31〜09/06）

## キャッチアップ（AI）

2.1.257
2026年9月2日

- Claude Fable 5.1（`claude-fable-5-1`）を追加し、Fableのデフォルトモデルになった。1Mコンテキスト、$10/$50 per Mtok、キャッシュ読み取り$0.25/Mtok
- 「Time format」（`timeFormat`）と `timeZone` 設定を追加。ターン終了時の時刻とトランスクリプトビューのタイムスタンプを12時間制・24時間制・24時間制UTC・strftimeパターンから選択可能
- `CLAUDE_CODE_SUBAGENT_MODEL_FORCE` を追加。spawn単位やエージェント定義のモデル指定を無視して `CLAUDE_CODE_SUBAGENT_MODEL`（またはメインモデル）を全サブエージェントに適用
- `/effort` に `s` を追加し、現在のセッションのみエフォートを変更可能に（`/model` と同様）
- killされたセッションが残した古いサンドボックスマスクファイルに対する `/doctor` 警告を追加
- autoモードで作業ディレクトリ外の最初のファイル読み取りの前に一度だけ確認プロンプトを表示し、そうした読み取りをブロックする選択肢を追加（`permissions.blockReadsOutsideWorkingDirectories`）
- `/model` ピッカーで検出されたエントリについて、ゲートウェイ提供の `description` をサポート（`CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY`）。`description` 無しのエントリは従来どおり「From gateway」と表示
- [VSCode] セッション一覧パネルに折りたたみ可能なACCOUNT & USAGE / SESSION MANAGERセクションヘッダーを追加。アカウントのメールアドレス、使用量メーター、使用量ダイアログを開くView detailsリンクを表示
- [VSCode] 入力フッターに現在のモデルを表示しモデルピッカーを開くモデルピルを追加（Effort行と「More models」ページ付き）
- [VSCode] セッション一覧のUngroupedセクションに折りたたみトグルを追加
- [VSCode] コマンドメニューに出力スタイルの選択を追加（カスタムスタイルを含む）

- [VSCode] セッション一覧サイドバーにActiveクイックフィルタとステータスフィルタメニュー（Needs input、Working、Completed）を追加
