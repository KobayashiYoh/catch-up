## キャッチアップ（モバイルアプリ開発）

Android 17
2026年6月16日

- Android 17（API レベル 37）を正式リリース。対応するPixel端末の大半で提供開始し、AOSPでソースコードを公開
- API レベル 37 をターゲットにしたアプリは、大画面端末（sw600dp以上）で画面の向き・リサイズ制限をオプトアウトできなくなった。`screenOrientation`、`setRequestedOrientation()`、`resizeableActivity=false`、`minAspectRatio` / `maxAspectRatio` は無視される（Google Playでゲームに分類されるアプリは除く）
- AppFunctionsを拡張。アプリの機能をオンデバイス版MCP（Android MCP）のツールとして公開し、GeminiなどのAIエージェントから実行可能に（Jetpackライブラリはalpha）
- 任意のアプリをフローティング表示できるApp Bubbles、大画面向けのBubble Bar、デスクトップ環境で操作可能なPiPを追加
- キーボード接続やカラーモード変更など一部の構成変更で、デフォルトではActivityを再生成せず `onConfigurationChanged()` で通知するよう変更
- 出典: https://android-developers.googleblog.com/2026/06/Android-17.html

## 学んだこと

- Apple Eventsとは、macOS上でアプリ同士が操作や情報をやり取りするための仕組み
- Apple Eventsを使うと、AppleScriptからFinderでフォルダを開いたり、Safariで指定したURLを開いたり、メールアプリでメールを作成したりできる
- Apple Eventsを使うと、Apple Events対応アプリなら対応している操作も実行できる
- AOSP（Android Open Source Project）とは、Androidのソースコードを公開しているオープンソースプロジェクト
- Android 17以降、大型端末においてゲーム以外のアプリはアプリ側で画面の回転を固定できなくなった
- AppFunctionsとは、AndroidアプリをAI側から操作してもらうための機能
- App Intentsとは、AppFunctionsのiOS版（Apple Intelligence対応端末のみ）
- App Bubblesとは、アプリを他のアプリ上に浮かぶウィンドウとして表示できる機能
- Bubble Barとは、大画面端末でアプリを切り替えるためのバー
- PiP（Picture in Picture）とは、動画などを小さなウィンドウで他の画面の上に重ねて表示する機能
