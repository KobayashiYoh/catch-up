# 2026-W37週次レポート（09/07〜09/13）

## キャッチアップ（AI）

2.1.265
2026年9月9日

- `user.email` と `user.groups` を、Claude DesktopとCoworkがClaude apps gateway経由で送るテレメトリに追加（ターミナルセッションと統一）
- `--plugin-dir` にプラグインのフォルダ群を指定できるようサポート。マニフェストを持つ各子フォルダが読み込まれ、実行中の子フォルダの追加・削除も反映される
- ディスクに保存されるツール結果に1GBの上限を追加。会話内のプレビューには保存ファイルが切り詰められた旨を表示
- [VSCode] 一定期間非アクティブなセッションの自動アーカイブを追加（新設定「Archive inactive sessions」、デフォルト14日）

---

2.1.267
2026年9月10日

- `maxEffortLevel` 設定を追加（トップレベル、または `modelSettings` 配下のモデル単位）。Bedrock / Vertex / Foundryを含む全プロバイダでエフォートレベルの上限を設定でき、ユーザーはより低いレベルを選択可能
- `--system-prompt-snapshot off` を追加。会話に記録されたプロンプトを再利用せず、毎リクエストでシステムプロンプトを新規レンダリング（プロンプト文面の反復開発向け）
- [Claude Tag] Claude Tag管理設定のプリセット接続フォームに「Use a custom connector」リンクを追加し、最初からやり直さずにカスタム接続へ切り替えられるようになった

---

2.1.268
2026年9月11日

- Claude apps gatewayで `gateway.yaml` に `pricing:` を設定すると、サインイン済みのClaude Codeクライアントがマネージド設定経由で同じレートを受け取り、`/cost` とテレメトリが支出メーターと一致するようになった
- `access_control.allow_cidrs` が空の場合のゲートウェイ起動時警告と、パブリックアドレスから最初にリクエストが来た際の一度きりの警告を追加
  - acess_controllにはallow_cidrsとdeny_cidrsがあり、IPアドレス範囲で許可と禁止を指定できる
- `gatewayInternalNetworks` マネージド設定を追加。管理者が組織自身のパブリックIPv4ブロックからのClaude apps gatewayへの `/login` を許可できる
- `claude self-hosted-runner --remove-session-state`（デフォルトはオフ）を追加。セッション終了時に `<base-dir>/_sessions/` 配下のセッション単位ディレクトリを削除
- `claude auth status --json` の出力に `configDirectory` を追加
- `claude plugin install` / `uninstall` / `update` / `enable` / `disable` に `--json` を追加し、`claude plugin list --json` の各行に `errorDetails` / `noteDetails` を追加
- 公開されたアーティファクトにブラウザのタブアイコンを追加（Claudeが各ページに合わせて選択）
- [VSCode] always-allow権限ルールの保存先を左右矢印キーで変更できるように追加（キーボード・スクリーンリーダー利用者向け）
- [VSCode] 会話内の最新メッセージへキーボードフォーカスを移す「Claude Code: Focus last message」コマンドを追加（キーボード・スクリーンリーダー利用者向け）
- [Claude Tag] Slackチャンネルの設定ページから組織のClaude in Slack管理設定へのリンクを追加
- [Code Review] フォローアップレビューの未解決指摘リストの下に注記を追加。スレッドに返信するだけでなく解決（resolve）しないと、以降のレビューで未解決として数えられ続ける

2.1.269
2026年9月12日

- `claude plugin eval` を追加。プラグインのevalスイートをClaude Codeに対して実行し、スコア付きで再現可能な結果（JSON + HTMLレポート）を取得できる（`claude plugin eval --help` 参照）
  - evalはevaluationの略
- `/output-style [name]` を追加。出力スタイルの一覧と切り替えを、Remote Control経由やクラウド・その他のヘッドレスセッションでも可能に
- Bashツールがファイル編集を扱う場合に、Bashコマンドが変更したファイルのdiffをツール結果に追加（設定 `bashEditDiffEnabled`）
  - ファイル変更時に差分を+-で表示できる
  - デフォだとauto モードと bypassPermissions モードはオンで、それ以外のモードはオフ
- `OTEL_METRICS_INCLUDE_REPOSITORY` を追加。OpenTelemetryのメトリクスとイベントに `vcs.*` リポジトリ属性を付与し、`OTEL_LOG_TOOL_DETAILS` 併用時はコミットイベントに `vcs.ref.head.*` が付く
- `CLAUDE_CODE_GATEWAY_MODEL_DISCOVERY_TIMEOUT_MS` を追加し、LLMゲートウェイの `/v1/models` 検出タイムアウト（デフォルト3秒）を延長可能に
- プロンプト・1行の作業サマリ・応答だけのビューを提供する `/focus` を勧めるスピナーTipを追加
    - focusを実行で出力を簡素化できる
- `CLAUDE_CODE_WORKFLOW_MAX_CONCURRENT_AGENTS`（1〜256）を追加し、推論バウンドなファンアウト向けにWorkflowツールの実行あたり同時エージェント数上限を引き上げ可能に
- [VSCode] エージェントマップを追加。「N agents」フッターピルからセッションのサブエージェントのマップを開き、エージェントごとのカード、Stop agent、読み取り専用トランスクリプトを表示
- [VSCode] コマンドメニューにHooksダイアログを追加。ユーザー・プロジェクト・ローカル設定のフックを閲覧・追加・編集・削除でき、マネージド・プラグイン・セッションのフックは読み取り専用
- [VSCode] Focusビューのツール呼び出しグループ配下に、実行中サブエージェントのライブ進捗行を追加
- [VSCode] Permission rulesダイアログを追加。権限ルールを一覧し、ユーザー・プロジェクト・ローカル設定で追加・削除でき、起動オプション・セッション限定・マネージドのルールは読み取り専用
- [VSCode] Switch account画面に、現在のアカウントのままセッションへ戻るCancelボタンを追加
- [Claude Code on the web] クラウドセッションでClaudeが読む前のキュー済みメッセージを取り消せるように追加。キューから削除するかEscまたはUpを押すとテキストがメッセージボックスに戻る
- [Claude Tag] 管理設定のGitHubインストールに対するConnect all / Disconnectの前に確認ダイアログを追加し、組織全体への誤操作を防止
- [Claude Tag] Slackチャンネルのスケジュールルーティンを改善。ルーティン実行が常に新しいトップレベルメッセージを投稿するのではなく、既存スレッドに返信できるようになった
