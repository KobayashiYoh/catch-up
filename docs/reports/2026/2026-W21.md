## キャッチアップ（モバイルアプリ開発）

- Flutter 3.44.0リリース
  - https://docs.flutter.dev/release/release-notes/release-notes-3.44.0
  - `RawMenuAnchor` のクローズ順序変更：親メニューを閉じると子孫が自動クローズされるようになり、`closeChildren()` の手動呼び出しが不要に
    - https://api.flutter.dev/flutter/widgets/RawMenuAnchor-class.html
  - `onReorder` コールバック廃止：`onReorderItem` に置き換え。インデックス調整（`newIndex -= 1`）が不要になった
  - `TextInputConnection.setStyle` 廃止：`updateStyle(TextInputStyle(...))` に置き換え。
  - `cacheExtent` / `cacheExtentStyle` 廃止：`scrollCacheExtent` に統合。
  - `IconData` クラスが `final` に：継承・実装が不可に。
  - `ListTile` をカラー Widget でラップするとデバッグエラー
  - Flutter Android プロジェクトの Kotlin 移行：AGP 9.0 以降で `kotlin-android` プラグイン (KGP) が廃止。
  - `CupertinoPageTransitionsBuilder` の移動

## 学んだこと

- `/resume`を使うと間違えて閉じたタブも再開できる（直近15件まで）
- `claude agents`を使うと今いるClaudeのセッションを見られる
- `claude agents --json`により、Claude以外のツールもClaudeの状態を読めるようになった
- `claude_code.tool` OTELスパンに`agent_id`と`parent_agent_id`属性が追加されたことで、AI内部の呼び出しログが親子関係付きでデバッグしやすくなった
- `onReorder`から`onReorderItem`への移行は、`dart fix`非対応のため手動移行が必要
- `onReorderItem`は、アイテムの並び替えが完了した時に呼ばれるコールバック
- `TextInputConnection.updateStyle(TextInputStyle(...))`は`letterSpacing` / `wordSpacing` / `lineHeight`に対応し、IMEカーソルずれが解消した
- `scrollCacheExtent`は、`ScrollCacheExtent.pixels()`または`ScrollCacheExtent.viewport()`で指定する
- `IconData`を implements した独自 enum はコンパイルエラーになるため、ラッパークラスへの移行が必要
- `Container(color:...)`と`Material`の間に`ListTile`があるとインクスプラッシュが隠れるため、背景色は`Material`側に移動する
- 要するに、AGP 9.0以降ではKGPがAGPに統合される
- AGP 9.0以降でKGPを使っているとビルドが失敗する恐れあり
- AGP 9.0以降では、`build.gradle`をAGP組み込みのKotlinに移行が必要
- AGP組み込みのKotlinへの移行作業は以下の通り
  ```
  // 変更前
  apply plugin: 'com.android.application'
  apply plugin: 'kotlin-android'   // ← 削除
  android {
      kotlinOptions {              // ← 削除
          jvmTarget =
  JavaVersion.VERSION_17.toString()
      }
  }
  // 変更後
  apply plugin: 'com.android.application'
  android {
      // kotlinOptions ブロックは不要
  }
  kotlin {
      compilerOptions {            // ← 追加
          jvmTarget =
  org.jetbrains.kotlin.gradle.dsl.JvmTarget.JVM_17
      }
  }
  ```
- `CupertinoPageTransitionsBuilder`は`package:flutter/material.dart`から`package:flutter/cupertino.dart`に移動したため、iOSスタイルの画面遷移を使う場合は import の追加が必要
