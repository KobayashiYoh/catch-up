# 2026-W38週次レポート（09/14〜09/20）

## キャッチアップ（AI）

2.1.271
2026年9月15日

- Claude Code Remoteセッション（クラウドおよびセルフホストランナー）でfastモードを追加。組織が許可する範囲で、ホストのfastモード設定またはセッション内で入力した `/fast` が適用される
- フルスクリーンモードの `/config` パネルにマウスサポートを追加。ホイールで設定リストをスクロール、設定の値をクリックで変更、ポインタ下の行をハイライト
- `claude self-hosted-runner --drain-marker-file <path>` を追加。SIGTERMによるドレイン時にそのファイルが存在すれば、ランナーがサーバーへ自身の終了をホストドレインとして報告（テレメトリのみ）
- サンドボックス有効なautoモードで、Bash / PowerShell / Monitorにコマンド単位の `allowed_domains` を追加。コマンドが必要とするホストがそのコマンドと一緒にレビューされ、そのコマンドにだけ開放される。他のホストは拒否
- エージェントfrontmatterと `--agents` JSONに `omitClaudeMd` を追加し、カスタム・プラグインのサブエージェントをユーザー・プロジェクト・ローカルのCLAUDE.md無しで実行可能に。マネージドポリシーファイルは引き続き読み込まれる
- `claude plugin install` と `claude plugin update` に `--accept-command <sha256>` を追加。`-y` の代わりに、直前の `--json` 実行が表示したコマンドそのものだけを承認できる
- `modelPricing` マネージド設定とClaude apps gatewayの `pricing` ブロックで、1より大きく10までの `multiplier` をサポート（社内チャージバック用の上乗せレート向け）
- Bedrock / Vertex AI / Foundry / LLMゲートウェイ利用者にClaudeデスクトップアプリを案内するスピナーTipを追加。claude.aiデスクトップアプリのTipはアプリのダウンロードを提案する `/desktop` を勧めるようになった
- [VSCode] Attach Open File設定を追加。オフにすると開いているファイルがメッセージに添付されなくなる（選択テキストは引き続き添付）
- [Claude Code on the web] 管理設定のCloud environmentsエディタにCustom network accessオプションを追加（claude.ai/codeの環境ダイアログと同じ許可ドメインリスト）

2.1.274
2026年9月17日

- メモリ使用量が危機的な場合に、メモリ解放手順や安全な再起動方法を示す可視の警告を追加
- `CLAUDE_CODE_MCP_STARTUP_WAIT_MS` を追加し、最初の非インタラクティブターンが接続中のMCPサーバーを待つ時間を制限可能に（`0` は待たない）
- `claude_code.llm_request` OpenTelemetryトレーススパンに `effort` 属性を追加（`api_request` イベントと統一）
- `claude_code.managed_settings_resolved` OTelイベントを追加。マネージド設定のソースとポリシーヘルパーの状態を記録し、`OTEL_LOG_MANAGED_SETTINGS=1` で秘匿済み設定とダイジェストも記録
- Claude apps gatewayの設定に `store.connect_timeout_seconds` を追加し、Postgresの接続タイムアウト（デフォルト5秒）を延長可能に。データベースに到達できない場合のbootエラーも `store.postgres_url` と設定済みタイムアウトを示すよう改善
- Claude DesktopとCoworkがClaude apps gateway経由で送るテレメトリに、IdPのサブジェクトである `enduser.sub` を追加
- レプリカが同時にアップストリームへ送る上限256を超えるリクエストを開いている場合のClaude apps gateway警告と、その上限を示す起動ログ行を追加
- フルスクリーンモードで折りたたまれたteammate・エージェントのメッセージをクリックで展開できるように追加
- [VSCode] ウィンドウのリロードで中断されたステップの継続をチャット上にラベル付きで追加し、Claude Code: Continue After Reload設定でオフにできるようになった
- [VSCode] CustomizeメニューにMemoryとInstructionsの項目を追加。Memoryでは自動メモリのトグル、保存済みメモリ、メモリフォルダを表示し、InstructionsではCLAUDE.mdファイルを編集
- [VSCode] Claudeが開いたエディタグループのロックを止める `claudeCode.lockEditorGroups` 設定を追加
- [Claude Code on the web] クラウドセッションのdiffビューに「Compare against」ブランチピッカーを追加し、ベースブランチ以外の任意のブランチと差分比較可能に
- [Claude Tag] Claude Tag管理設定のAdd channel / Add workspaceフォームにGuests設定を追加し、オーナーがInherit / Allow / Channel only / Restrictを事前に選択可能に
