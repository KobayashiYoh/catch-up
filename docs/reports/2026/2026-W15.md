- `/reload-plugins` がプラグイン提供のスキルを再起動なしで取り込むよう改善
- Accept Editsモードで、安全な環境変数やプロセスラッパーをプレフィックスに持つファイルシステムコマンドを自動承認するよう改善
- VimモードのNORMALモードで `j` / `k` が履歴をナビゲートし、入力の境界でフッターピルを選択するよう改善
- トランスクリプト内のフックエラーにstderrの1行目を含めるよう改善し、`--debug` なしで自己診断できるようになった
- OTELトレーシングを改善。並行SDK呼び出し下でもinteractionスパンがターン全体を正しくラップし、ヘッドレスのターンはターンごとにスパンを終了する
- トランスクリプトのエントリがストリーミング時のプレースホルダではなく最終的なトークン使用量を保持するよう改善
- `/claude-api` スキルを更新し、Claude APIに加えてManaged Agentsをカバー

- focusモードを改善。最終メッセージのみが表示されることをClaudeが認識するため、より自己完結的なサマリを書くようになった
- モデルが存在するが現在のコンテキストでは利用できないツールを呼び出した際、理由と対処方法を説明するようツール未提供エラーを改善
- レート制限のリトライメッセージを改善し、不明瞭な秒数カウントダウンではなくどの制限に到達しどの時点でリセットされるかを表示
- 拒否エラーのメッセージを改善し、APIが提供する説明があればそれを含めるようになった
- `claude -p --resume <name>` が `/rename` や `--name` で設定したセッションタイトルを受け付けるよう改善
- 設定の堅牢性を改善。`settings.json` 内に未知のフックイベント名があってもファイル全体が無視されないようになった
- 管理設定で強制有効化されたプラグインのフックが、`allowManagedHooksOnly` 設定時にも実行されるよう改善
- `/plugin` と `claude plugin update` で、マーケットプレイスを更新できなかった場合に古いバージョンを黙って報告するのではなく警告を表示するよう改善
- ユーザーの組織や認証構成からWeb上のClaude Codeへ到達できない場合、プランモードでRefine with Ultraplanオプションを非表示にするよう改善
- ベータのトレーシングが `OTEL_LOG_USER_PROMPTS`、`OTEL_LOG_TOOL_DETAILS`、`OTEL_LOG_TOOL_CONTENT` を尊重するよう改善。オプトインしない限り機微なスパン属性は出力されない
- SDKの `query()` を改善し、コンシューマが `for await` から `break` した場合や `await using` を使った場合にサブプロセスと一時ファイルをクリーンアップするようになった

## 学んだこと

- デフォルトのeffortレベルがmediumからhighに変更されたため、デフォルトがmediumではなくなった点に注意
- `UserPromptSubmit`フックの`hookSpecificOutput.sessionTitle`により、セッションタイトルに独自のルールなどを適用しやすくなるので、セッションを見つけやすい
- Machとは、macOS内部でプロセス同士が通信するための仕組み
- Perforce(p4)とは、Gitのようなバージョン管理ツール
- LinuxでPID名前空間分離によるサブプロセスのサンドボックス化が追加されたことで、サブプロセスを隔離環境で実行できるようになった
- `/team-onboarding`コマンドを試しに実行してみると、Claude Codeの使用状況などを踏まえたガイドが生成された
- OSのCA証明書ストアをデフォルトで信頼するようになったことで、会社独自のCA証明書をOSに登録している場合の設定が楽に
