# 2026-W06週次レポート（02/02〜02/08）

## キャッチアップ（AI）

2.1.30
2026年2月3日

- `/insights`コマンドを追加。Claude Codeの利用状況を分析し、インタラクティブなHTMLレポートを生成できるようになった
- ReadツールでPDFの特定ページ範囲を指定できる`pages`パラメータを追加
- 10ページを超えるPDFを`@`で指定した際、PDF全体をコンテキストに埋め込まず軽量な参照を返すようになった
- Dynamic Client Registrationに対応していないMCPサーバー向けに、事前設定済みOAuthクライアント認証情報をサポート
  - DCR (Dynamic Client Registration)...OAuthのクライアントが認可サーバーに自分自身を登録する仕組み
  - 以前はDCR非対応のMCPサーバーにClaude CodeからOAuth接続できなかった
  - つまり、接続できるMCPサーバーの種類が増えた
- `claude mcp add`で`--client-id`と`--client-secret`を指定できるようになった
- `/debug`を追加し、現在のセッションのトラブルシューティングを行えるようになった
  - セッションで何か実行が失敗した際に原因を調査してくれる
- 読み取り専用モードの`git log`と`git show`で追加のオプションをサポート
- Taskツールの結果にトークン数、ツール使用回数、実行時間のメトリクスを追加
- Reduced Motionモードを設定に追加
  - アニメーションの表示を抑える設定
- プラグイン設定の正式なスキーマを追加
  - `plugin.json`の入力ミスに気づけるようになった
- Claude Code SDKの各種スキーマにフィールドの説明を追加

2.1.32
2026年2月5日

- Claude Opus 4.6を利用可能にした
- Agent TeamsのResearch Previewを追加し、複数のエージェントによる協調作業をサポート
- Claudeが作業中に自動的にメモリを記録・想起するAuto-Memoryを追加
- メッセージセレクターに「Summarize from here」を追加し、会話の途中から部分的に要約できるようになった
- `--add-dir`で指定した追加ディレクトリ内の`.claude/skills/`にあるSkillsを自動ロードするようになった
  - 起動したディレクトリ以外のskillを自動でロードできるようになった
- Skillの文字数上限がコンテキストウィンドウのサイズに応じて拡張されるようになった

2026年2月6日

- マルチエージェントワークフロー向けに`TaskCompleted` Hookイベントを追加
- Agentのfrontmatterで`Task(agent_type)`構文を使い、起動可能なSubagentの種類を制限できるようになった
- Agentのfrontmatterに`memory`フィールドを追加し、`user`、`project`、`local`スコープの永続メモリを指定できるようになった
- Skillsの説明と`/skills`メニューにプラグイン名を表示するようになった
- VS Code拡張でOAuthを利用したRemote Sessionに対応
- VS Code拡張のセッションピッカーにGitブランチとメッセージ数を表示し、ブランチ名で検索できるようになった
