## 学んだこと

- Status Lineとは、`Claude Sonnet 5 | ~/project | main`のようなClaude Code画面下部のカスタマイズ可能な表示エリア
- `Ctrl+G`でプロンプトを外部エディタで編集できる
- MCP Tool Searchとは、コンテキスト節約のためにMCPツールを必要になったときだけ検索してロードする仕組み
- `auto:N`は、MCPツールの説明を全部読むとコンテキストをN%以上消費する場合、自動的にMCP Tool Searchを有効化する
- MCP Tool Searchの自動有効化しきい値のデフォルトは`auto:10`
- Webセッションから作成したコミットやPull RequestにセッションURLが自動付与されるが、WebではなくローカルのClaude CodeのセッションをURL化する仕組みはなさそう
- `Setup` Hookは、リポジトリをクローンし、`claude --init`を実行した際に実行されるhooks
- REPL（Read-Eval-Print Loop）とは、Claude Codeの対話画面のこと
- REPLの起動完了前に入力されたキー入力を取得できるようになり、Claude Code起動待ち時に入力されたキーの入力を取りこぼさなくなった
