# 2026-W32週次レポート（08/03〜08/09）

## キャッチアップ（AI）

2.1.221
2026年8月4日

- [VSCode] Focus viewを追加。ツールのアクティビティをターンごとの展開可能なサマリーの背後に隠し、実行中ツールのライブインジケータを表示するチャットメニューのトグルで、`Ctrl+Alt+F`または「Claude Code: Toggle Focus view」コマンドで切り替える
- LinuxとWSLのサンドボックス認証情報ファイルに`mode: "mask"`を追加。サンドボックス実行コマンドはセンチネルのコピー（ファイル全体、または`extract`正規表現が捕捉した範囲のみ）を読み、サンドボックスプロキシがegress時に実際の値へ置換する。macOSではファイルマスキングは`deny`にフォールバックする
- `claude plugin validate`に、Claude Desktopのmanaged marketplace同期で拒否されるマーケットプレイス名・プラグイン名に対する警告を追加
- `claude-api`スキルに`prompt-audit`サブコマンドを追加。旧世代モデル向けに書かれたパターンについてプロンプトとツール説明を監査できる
- プラグインが`skills`パスとして`"."`を受理するようになった。ルートレベルの`SKILL.md`検証エラーはプラグインルートの使用を提案する
- `/status`がセッション種別を表示するようになった（`interactive`、または`attached` / `unattended`のバックグラウンドジョブ）

2.1.223
2026年8月6日

- `strictKnownMarketplaces`と`blockedMarketplaces`のmanaged設定に、GitHub org配下の全マーケットプレイスリポジトリを許可・ブロックするためのオーナーワイルドカードエントリ（`"owner/*"`）を追加
- ワークフローエージェント、フォークされたスキル、スラッシュコマンド、再開されたバックグラウンドエージェントが要求したサブエージェントモデルが制限されていて親のモデルが代わりに使われる場合に警告を追加

---

2.1.224
2026年8月7日

- セルフホスト環境を追加。`claude self-hosted-runner`により、自前のマシンやコンテナをClaude Codeのweb / mobile / desktopセッションの実行環境にできる（Team・Enterpriseプラン）
- `archive`プラグインソースを追加。gitやnpmなしでHTTPS経由のzipからプラグインをインストールでき、SHA-256でのピン留めもできる
- Bedrock向けに`ANTHROPIC_BEDROCK_REGION_PREFIX`環境変数を追加。`AWS_REGION`から導出されるものより特定のクロスリージョン推論プロファイルを優先できる
- `crossSessionInbound`と`dialogExpiry`設定を追加。パーミッションをバイパスして実行中のセッション宛のクロスセッションメッセージは承認待ちで保留され、他セッション宛のメッセージは自動配信される
- サンドボックスの認証情報マスキングオプションを追加。構造化されたenv値向けの`extract`と`onExtractNoMatch`、JWTを理解する`decode: "jwt"`と`maskClaims`、AWS SigV4の再署名用`awsPairs` / `sigv4`が使える。これらは`network.tlsTerminate`が必要で、user・managed・`--settings`の設定からのみ有効
- クロスセッション`SendMessage`を追加。Claude Codeのセッション同士が、任意の自分のマシン間でメッセージを送り合えるようになった。`ListAgents`で相手を検出する（macOSとLinux）

---

2.1.225
2026年8月8日

- Claude Codeの使用量警告にゲートウェイのspend-limitサポートを追加。上限到達メッセージに上限値・リセット時刻・運用者のメッセージが表示される（ゲートウェイ側も2.1.225が必要）
- 信頼されていないディレクトリに対する`claude agents`のワークスペース信頼プロンプトを追加（`claude`の挙動に合わせた）
- `SendMessage`が、相手から先にメッセージが来るのを待たずに、他のマシン上のRemote Controlセッションと名前指定（`ListAgents`に`name [ref]`として表示される）で会話を開始できるようになった
