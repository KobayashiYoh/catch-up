2026年8月13日

- 同梱のDartは3.13.0
- Material / Cupertino が独立パッケージ `material_ui` / `cupertino_ui`（v1.0）として提供開始。現時点ではオプトインで、コアSDKにも引き続き同梱されている
- 移行コマンドは `dart fix --apply --code=migrate_design_widgets`。コアSDK同梱のデザインライブラリは11月の安定版リリースで正式に非推奨化される予定と公式ブログに記載
- 最低OSバージョン引き上げ：iOS 13 → 15、macOS 10.15 → 12（Xcode 27 対応のため）
- iOS 27 SDK では UIScene ライフサイクルが必須。未対応のまま Xcode 27 でビルドしたアプリは起動に失敗する。通常は Flutter CLI が自動移行するが、独自の `AppDelegate` 処理やレガシープラグインがある場合は手動移行が必要
- Swift Package Manager：人気上位100のiOSプラグインのうち92件が移行済み。CocoaPods はメンテナンスモード。有効化は `flutter config --enable-swift-package-manager`
- Widget Previews が安定版に
- Android：ハイコントラスト・色反転を `MediaQueryData.highContrast` / `MediaQueryData.invertColors` で検出可能に。検証済み構成は Java 17 / KGP 2.4.0 / AGP 9.1.0 / Gradle 9.3.1、compileSdk・targetSdk は API 36、minSdk は API 24
- デスクトップ（macOS / Windows / Linux）で Impeller がデフォルトレンダラーに
- `Semantics` の `header` が iOS / Android で無効（no-op）に。見出しの指定は `headingLevel` に置き換え、`header: true` → `headingLevel: 1`（0より大きい値）
- `describeEnum` 削除：`Theme.light.name` のように `Enum` の `name` ゲッターを使う。**`dart fix` 非対応** のため手動移行が必要
- Dart 3.13：プライマリコンストラクタ追加（`sdk: '^3.13.0'` 以上で利用可）。`class Point(var int x, var int y);` のようにクラス宣言の先頭でフィールドとコンストラクタを宣言できる。破壊的変更として、通常のパラメータに `final` / `var` を付けられなくなった

## 学んだこと

- Dialog expiryのexpiryとは、有効期限の意味
- `/advisor`とは、Claude Codeの適切な使い方について、別のAIモデルにレビューさせるもの
- `forward_user_identity` apps gateway設定は、Claude Codeの利用料金を誰が使った分なのかユーザー単位で集計できるようにする設定
- cgroup（control group）とは、Linuxでプロセス群のCPUやメモリなどのリソースを管理する仕組み
- `CLAUDE_CODE_TOOL_MEMORY_LIMIT`により、メモリの使用量を制限し、制限を超えたプロセスをOS側で制御できるようになった
- `flutter config --enable-swift-package-manager`は、FlutterでSwift Package Managerを有効化するコマンドであって、SPMへ移行するコマンドではない
- 色反転はアクセシビリティの一環であり、画面の色を見分けにくい人のための機能
- Impellerは、従来のSkiaと比較してビルド時にシェーダーをコンパイルするので、描画時のカクつきを減らす
- シェーダーとは、GPUに画面のこの部分をどんな色、見た目で描くかを提示するプログラム
- `Semantics`とは、画面の情報をスクリーンリーダーに伝える仕組みで、見出しの階層を指定するWidget
- Enumから文字列を取り出すのに、`describeEnum(Theme.light)`ではなく、`Theme.light.name` を使うようになった
- Dart 3.13のプライマリコンストラクタを使うと、従来のコンストラクタのように`this`を使って1つずつフィールドを初期化する必要がなくなる
- `void greet(final String name)`のようにパラメータに`final` / `var`を付けられなくなったが、通常の変数宣言には引き続き使用できる
