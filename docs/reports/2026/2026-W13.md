# 2026-W13週次レポート（03/23〜03/29）

## キャッチアップ（AI）

2.1.83
2026年3月25日

- `managed-settings.json` と並ぶ `managed-settings.d/` ドロップインディレクトリを追加。複数チームが独立したポリシー断片をデプロイし、アルファベット順にマージされる
  - settings.jsonはユーザーが管理し、managed-settings.jsonは組織の管理者が管理する
  - 設定ファイルを複数チームで分割し、アルファベット順に適応できる
- リアクティブな環境管理（direnvなど）向けに `CwdChanged` と `FileChanged` フックイベントを追加
  - CwdChanged...作業ディレクトリが変わった際に発火するフック
  - 特定のファイルが変更されたときに発火するフック
- サンドボックスが有効だが起動できない場合に、非サンドボックスで実行するのではなくエラー終了する `sandbox.failIfUnavailable` 設定を追加
- `claude-cli://` プロトコルハンドラの登録を防ぐ `disableDeepLinkRegistration` 設定を追加
- サブプロセス環境（Bashツール、フック、MCP stdioサーバー）からAnthropicおよびクラウドプロバイダの認証情報を除去する `CLAUDE_CODE_SUBPROCESS_ENV_SCRUB=1` を追加
  - Claudeが起動した子プロセスにClaudeが持つ認証情報を渡さないようにする仕組み
- ストリーミング失敗時の非ストリーミングフォールバックを無効化する `CLAUDE_CODE_DISABLE_NONSTREAMING_FALLBACK` 環境変数を追加
- トランスクリプト検索を追加。トランスクリプトモード（`Ctrl+O`）で `/` を押して検索し、`n` / `N` でマッチ間を移動する
  - セッションの会話履歴における検索機能
- 外部エディタを開く `Ctrl+X Ctrl+E` のエイリアスを追加（readlineネイティブのバインド。`Ctrl+G` も引き続き有効）
- ペーストした画像がカーソル位置に `[Image #N]` チップを挿入し、プロンプト内で位置を指定して参照できるようになった
- エージェントがフロントマターで `initialPrompt` を宣言し、最初のターンを自動送信できるようになった
- `chat:killAgents` と `chat:fastMode` を `~/.claude/keybindings.json` でリバインドできるようになった
- 「stop all background agents」のキーバインドを `Ctrl+F` から `Ctrl+X Ctrl+K` へ変更（readlineのforward-charをシャドウしないため）
- `TaskOutput` ツールを非推奨化し、バックグラウンドタスクの出力ファイルパスに対する `Read` の使用を推奨
- プラグインオプション（`manifest.userConfig`）を外部公開。プラグインが有効化時に設定を尋ねられるようになり、`sensitive: true` の値はキーチェーン（macOS）または保護された認証情報ファイル（その他のプラットフォーム）に保存される
- Claudeがクリップボードからペーストされた画像のディスク上パスをファイル操作で参照できるようになった
- `Ctrl+L` が画面をクリアして完全再描画を強制するようになった。Cmd+KでUIが部分的に空白になった場合の復帰に使用する。プロンプト入力のクリアには `Ctrl+U` またはEsc二度押しを使う
- 応答前にプロンプトを中断した場合、入力が自動的に復元され、編集して再送信できるようになった
- `/status` がClaudeの応答中でもターン終了までキューイングされずに動作するようになった
- メモリの `MEMORY.md` インデックスが200行に加えて25KBでも切り詰められるようになった
- `--channels` が有効な場合、`AskUserQuestion` とプランモードのツールを無効化
- 組織管理のコネクタと重複するプラグインMCPサーバーは、2つ目の接続を張るのではなく抑制されるようになった
- 非ストリーミングフォールバックのトークン上限（21k→64k）とタイムアウト（ローカルで120秒→300秒）を引き上げ、フォールバックリクエストが切り詰められにくくなった
- bashのゴーストテキスト候補が、送信直後のコマンドを即座に含むようになった
- Linuxで `claude-cli://` プロトコルハンドラ登録時に `XDG_DATA_HOME` を尊重
- `WebFetch` が `Claude-User` として自身を識別するよう改善し、サイト運営者が `robots.txt` でClaude Codeのトラフィックを認識・許可できるようになった
- プロファイル取得を他の起動処理とオーバーラップさせ、Bedrock SDKのコールドスタートレイテンシを改善
- 大きなセッションでの `--resume` のメモリ使用量と起動レイテンシを改善
- プラグインの起動を改善。コマンド、スキル、エージェントを再取得せずディスクキャッシュから読み込む
- Remote Controlのセッションタイトルを改善。AI生成タイトルが最初のメッセージから数秒以内に表示される
- 未認証のHTTP/SSE MCPサーバーがある場合の `claude -p` の起動を約600ms高速化
- `--bare -p`（SDKパターン）がAPIリクエストまで約14%高速化
- 大きなページに対する `WebFetch` のピークメモリ使用量を削減
- 長時間セッションでのスクロールバックのリセットを、1ターンに1回から約50メッセージに1回へ削減
- [VSCode] バックエンドが60秒応答しない場合、スピナーが赤くなりNot respondingを表示
- [VSCode] Esc二度押し（または `/rewind`）でキーボード操作可能なrewindピッカーを開けるようになった

2.1.84
2026年3月26日

- Windows向けPowerShellツールをオプトインのプレビューとして追加
- サードパーティ（Bedrock、Vertex、Foundry）でピン留めされたデフォルトモデルのeffort/thinking機能検出を上書きする `ANTHROPIC_DEFAULT_{OPUS,SONNET,HAIKU}_MODEL_SUPPORTS` 環境変数を追加。`/model` ピッカーのラベルをカスタマイズする `_MODEL_NAME` / `_DESCRIPTION` も追加
- ストリーミングのアイドル監視しきい値を設定する `CLAUDE_STREAM_IDLE_TIMEOUT_MS` 環境変数を追加（デフォルト90秒）
- `TaskCreate` によるタスク生成時に発火する `TaskCreated` フックを追加
- `WorktreeCreate` フックで `type: "http"` をサポート。レスポンスJSONの `hookSpecificOutput.worktreePath` で作成したworktreeのパスを返す
  - ワークツリーを作った後の環境構築まで自動化したい場合に使う機能
- Team/Enterprise管理者がチャネルプラグインの許可リストを定義する `allowedChannelPlugins` 管理設定を追加
- タイムアウトのデバッグ用に `x-client-request-id` ヘッダをAPIリクエストへ追加
- 75分以上ぶりに戻ってきたユーザーへ `/clear` を促すアイドル復帰プロンプトを追加し、古いセッションでの不要なトークン再キャッシュを削減
- ディープリンク（`claude-cli://`）が検出リストの先頭のターミナルではなく、優先ターミナルで開くようになった
- Rulesとスキルの `paths:` フロントマターでglobのYAMLリストを受け付けるようになった
  - Skill/Ruleをこのファイルに関係するものと記述しておく
  - 指定したファイルの種類ごとにルールを分割できる
  - 「このルールはxxx用」と教えるだけならSkill本文、「このファイルを扱うときだけ、このルールを有効にする」と設定するのがpaths
- MCPのツール説明とサーバーinstructionsを2KBで上限設定し、OpenAPI生成サーバーによるコンテキスト肥大化を防止
- ローカル設定とclaude.aiコネクタの両方で設定されたMCPサーバーを重複排除（ローカル設定を優先）
- 対話的プロンプトで止まっているように見えるバックグラウンドbashタスクが約45秒後に通知を出すようになった
- 100万以上のトークン数を1512.6kではなく1.5mと表示
- `ToolSearch` 有効時（MCPツールを設定しているユーザーを含む）でもグローバルなシステムプロンプトキャッシュが機能するようになった
- issue/PRの参照を `owner/repo#123` の形式で書かれた場合のみリンク化するよう変更。単独の `#123` は自動リンクしない
- 現在の認証構成で利用できないスラッシュコマンド（`/voice`、`/mobile`、`/chrome`、`/upgrade` など）を表示ではなく非表示に
- Windowsのドライブルート（`C:\`、`C:\Windows` など）に対する危険な削除の検出を改善
- `setup()` をスラッシュコマンド/エージェントの読み込みと並列化し、対話起動を約30ms改善
- MCPサーバーがある状態での `claude "prompt"` の起動を改善。全サーバーの接続完了を待たずにREPLが即座に描画される
- Remote Controlがブロックされている場合、汎用のnot yet enabledではなく具体的な理由を表示するよう改善
- p90のプロンプトキャッシュ率を改善
- メッセージウィンドウをコンパクションやグルーピングの変更の影響を受けないようにし、長時間セッションでのスクロール位置トップへのリセットを削減
- アニメーション付きツール進捗がビューポートより上へスクロールした際のターミナルのちらつきを削減
- `/stats` のCtrl+Sによるスクリーンショットが全ビルドで動作するようになり、16倍高速化
- [VSCode] 使用率とリセット時刻を表示するレート制限警告バナーを追加

2.1.85
2026年3月27日

- MCPの `headersHelper` スクリプトへ `CLAUDE_CODE_MCP_SERVER_NAME` と `CLAUDE_CODE_MCP_SERVER_URL` 環境変数を追加し、1つのヘルパーで複数サーバーを扱えるようになった
- 権限ルール構文（例: `Bash(git *)`）を使ってフックの実行条件を絞る `if` フィールドを追加し、プロセス生成のオーバーヘッドを削減
  - Hooksの発火に条件を設定できる
- スケジュール済みタスク（`/loop`、`CronCreate`）が発火した際のタイムスタンプマーカーをトランスクリプトへ追加
- 画像ペースト時の `[Image #N]` プレースホルダの後に空白を追加
- ディープリンククエリ（`claude-cli://open?q=…`）が最大5,000文字をサポート。長い事前入力プロンプトにはscroll to reviewの警告を表示する
- MCP OAuthがRFC 9728のProtected Resource Metadataディスカバリに従って認可サーバーを検出するようになった
- 組織ポリシー（`managed-settings.json`）でブロックされたプラグインはインストール/有効化できなくなり、マーケットプレイスのビューからも非表示になった
- PreToolUseフックが `permissionDecision: "allow"` と併せて `updatedInput` を返すことで `AskUserQuestion` を満たせるようになった。独自UIで回答を収集するヘッドレス統合が可能
- OpenTelemetryのtool_resultイベント内の `tool_parameters` を `OTEL_LOG_TOOL_DETAILS=1` でゲート
- 大規模リポジトリでの `@` メンションのファイル自動補完の性能を改善
- PowerShellの危険コマンド検出を改善
- WASMのyoga-layoutを純粋なTypeScript実装へ置き換え、大きなトランスクリプトでのスクロール性能を改善
- 大きなセッションでコンパクションが発生した際のUIのもたつきを削減
