# 2026-W18週次レポート（04/27〜05/03）

## キャッチアップ（AI）

2.1.121
2026年4月28日

- MCPサーバー設定に`alwaysLoad`オプションを追加。`true`にするとそのサーバーの全ツールがツール検索の遅延をスキップし、常に利用可能になる
- `claude plugin prune`を追加。自動インストールされた孤立プラグイン依存を削除する。`plugin uninstall --prune`でカスケード削除できる
- `/skills`に入力フィルタ用の検索ボックスを追加。長いリストでもスクロールせずスキルを探せる
- PostToolUseフックが`hookSpecificOutput.updatedToolOutput`で全ツールのツール出力を置き換えられるようになった（従来はMCPのみ）
- フルスクリーンモードで、過去の出力を読むためにスクロールアップした後にプロンプトへ入力しても、スクロールが最下部に戻らなくなった
- ターミナルに収まらないダイアログが、フルスクリーン・非フルスクリーンの両モードで矢印キー、PgUp／PgDn、home／end、マウスホイールでスクロールできるようになった
- フルスクリーンモードで複数行に折り返した長いURLの、どの行をクリックしてもURL全体が開くようになった
- SDKと`claude -p`: 非インタラクティブなセッションでも`CLAUDE_CODE_FORK_SUBAGENT=1`が機能するようになった
- `--dangerously-skip-permissions`が`.claude/skills/`、`.claude/agents/`、`.claude/commands/`への書き込みでプロンプトを出さなくなった
- `/terminal-setup`がiTerm2の「Applications in terminal may access clipboard」設定を有効化し、tmux内も含め`/copy`が動作するようになった
- 起動時に一時的なエラーに遭遇したMCPサーバーが、切断状態のままにならず最大3回まで自動リトライするようになった
- ターミナルタブのセッションタイトルが、設定済みの`language`設定で生成されるようになった
- 同一の上流URLを持つclaude.aiコネクタが重複表示されず、重複排除されるようになった
- Vertex AI: X.509証明書ベースのWorkload Identity Federation（mTLS ADC）に対応
- アップグレード後の起動を高速化（リリースノートのスプラッシュからRecent Activityパネルを削除）
- LSPの診断サマリがクリック／`Ctrl+O`で展開できるようになり、展開ヒントを表示するようになった
- SDK: `mcp_authenticate`がカスタムスキームの完了とclaude.aiコネクタ向けに`redirectUri`に対応
- OpenTelemetry: LLMリクエストのスパンに`stop_reason`、`gen_ai.response.finish_reasons`、`user_system_prompt`（`OTEL_LOG_USER_PROMPTS`でゲート）を追加
- [VSCode] Claude Codeのlanguageが未設定の場合、音声ディクテーションが`accessibility.voice.speechLanguage`設定を尊重するようになった
- [VSCode] `/context`がネイティブのトークン使用量ダイアログを開くようになった
- Bashツールでの`find`実行時、大きなディレクトリツリーでのファイルディスクリプタのピーク使用量を削減

2.1.126
2026年5月1日

- `ANTHROPIC_BASE_URL`がAnthropic互換ゲートウェイを指している場合、`/model`ピッカーがゲートウェイの`/v1/models`エンドポイントからモデル一覧を表示するようになった
- `claude project purge [path]`を追加。プロジェクトのClaude Codeの状態（トランスクリプト、タスク、ファイル履歴、configエントリ）をすべて削除する。`--dry-run`、`-y`／`--yes`、`-i`／`--interactive`、`--all`に対応
- `--dangerously-skip-permissions`が`.claude/`、`.git/`、`.vscode/`、シェル設定ファイルなど、従来保護されていたパスへの書き込みでもプロンプトをバイパスするようになった（壊滅的な削除コマンドは安全網として引き続きプロンプトを表示する）
- `claude auth login`が、ブラウザのコールバックがlocalhostに到達できない場合（WSL2、SSH、コンテナ）に、ターミナルへ貼り付けたOAuthコードを受け付けるようになった
- `claude_code.skill_activated`のOpenTelemetryイベントが、ユーザーが入力したスラッシュコマンドでも発火するようになり、新しい`invocation_trigger`属性（`"user-slash"`、`"claude-proactive"`、`"nested-skill"`）を持つようになった
- autoモード: 権限チェックがストールした際、ツールが動作中のように見えるのではなくスピナーが赤くなるようになった
- ホスト管理型のデプロイ（`CLAUDE_CODE_PROVIDER_MANAGED_BY_HOST`）が、Bedrock／Vertex／Foundryでanalyticsを自動無効化しなくなった
- Windows: Microsoft Store経由、PATHなしのMSI、`.NET global tool`でインストールされたPowerShell 7を検出できるようになった
- Windows: PowerShellツールが有効な場合、Bashをデフォルトにせず、PowerShellを主要シェルとして扱うようになった
- Readツール: ファイルごとのマルウェア評価リマインダーを削除（旧世代モデルで誤った拒否や「this is not malware」というコメントを誘発していたため）
- リンタが多数のファイルを変更した場合の、ファイル変更リマインダーの合計サイズを制限
- Windows: クリップボードへの書き込みが、EDR／SIEMのテレメトリから見えるプロセスのコマンドライン引数にコピー内容を露出しなくなった（22KB超の選択範囲がクリップボードに届かない問題も解消）
- PowerShellツール: 単独の`--`（例: `git diff -- file`）が`--%`のパース停止トークンとして誤判定されなくなった

## 学んだこと

- MCPサーバー設定の`alwaysLoad`オプションにより、必要になったら検索するのではなく、最初から全ツールを使えるようになった
- `--dangerously-skip-permissions`が`.claude/skills/`、`.claude/agents/`、`.claude/commands/`への書き込みでプロンプトを出さなくなったため、勝手にスキルやエージェント、コマンドを書き換えられたくない場合は`--dangerously-skip-permissions`を無効化する
- iTerm2とは、Mac向けのターミナルアプリのこと
- Workload Identity Federation（WIF）とは、外部のワークロードのIDをGoogle CloudのIDに連携し、サービスアカウントキーなどの長期的な認証情報に依存せずに認証する仕組み
- `/resume`の検索ボックスにPRのURLを貼り付けてそのPRを作成したセッションを見つける機能は、GitHub、GitHub Enterprise、GitLab、Bitbucketに対応しているが、こういうGitHub優勢な所を見るとADOからGitHubへの移行を考えたくなる
- `claude project purge`は、開発が終わったプロジェクトの履歴がストレージを圧迫している際に使えそう
- `--dangerously-skip-permissions`がプロンプトをバイパスするとは、プロンプトの確認メッセージをスキップするという意味
- ホスト管理型のデプロイとは、組織や実行環境を設定・管理する方式のこと
