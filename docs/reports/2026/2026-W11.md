# 2026-W11週次レポート（03/09〜03/15）

## キャッチアップ（AI）

2.1.72
2026年3月10日

- `EnterWorktree` セッションを抜けるための `ExitWorktree` ツールを追加
  - ワークツリーの後片付けを実施する
- `/plan` に任意の説明引数を追加（例: `/plan fix the auth bug`）。プランモードへ入って即座に開始する
- `/copy` に `w` キーを追加し、フォーカス中の選択をクリップボードを経由せず直接ファイルへ書き出せるようになった（SSH越しで便利）
- セッション中にスケジュール済みcronジョブを即座に停止する `CLAUDE_CODE_DISABLE_CRON` 環境変数を追加
- bash自動承認の許可リストに `lsof`、`pgrep`、`tput`、`ss`、`fd`、`fdfind` を追加し、一般的な読み取り専用操作の権限プロンプトを削減
- 呼び出し単位のモデル上書きのため、Agentツールの `model` パラメータを復活
- effortレベルをlow/medium/highに簡素化（maxを削除）。新しい記号（○ ◐ ●）と、常設アイコンではなく短い通知を採用。`/effort auto` でデフォルトへリセットできる
- CLAUDE.mdのHTMLコメント（`<!-- ... -->`）を自動注入時にClaudeから隠すよう変更。Readツールで読んだ場合はコメントも見える
- `.git` サフィックスなしのマーケットプレイスgit URLをサポート（Azure DevOps、AWS CodeCommit）
- `/config` を改善。Escapeで変更をキャンセル、Enterで保存して閉じる、Spaceで設定をトグルする
- 複数の同時セッション実行時、上矢印の履歴で現在のセッションのメッセージを優先表示するよう改善
- リポジトリ名や一般的な開発用語（regex、OAuth、JSON）の音声入力の文字起こし精度を改善
- bashコマンドのパースをネイティブモジュールへ切り替え、初期化を高速化しメモリリークを解消
- gitがstderrを出力しない場合でも診断情報を表示するよう、マーケットプレイスのクローン失敗メッセージを改善
- バンドルサイズを約510KB削減
- 長時間セッションでのCPU使用率を改善
- [VSCode] 入力枠にeffortレベルインジケータを追加
- [VSCode] 新しいClaude Codeタブをプログラム的に開く `vscode://anthropic.claude-code/open` URIハンドラを追加。任意の `prompt` / `session` クエリパラメータに対応

2.1.73
2026年3月12日

- モデルピッカーのエントリをカスタムプロバイダのモデルID（例: Bedrockの推論プロファイルARN）へマッピングする `modelOverrides` 設定を追加
  - Claude Code上に表示されるモデル名と実際に呼び出すモデルを別々に設定できるようになった
- SSL証明書エラー（企業プロキシ、`NODE_EXTRA_CA_CERTS`）でOAuthログインや接続チェックが失敗した際に、実行可能なガイダンスを追加
- Bedrock/Vertex/Microsoft FoundryのデフォルトOpusモデルをOpus 4.6に変更（従来はOpus 4.1）
- `/output-style` コマンドを非推奨化し `/config` を使用するよう変更。出力スタイルはプロンプトキャッシュ改善のためセッション開始時に固定される
- Claudeを中断した後の上矢印を改善。中断したプロンプトを復元し、会話を1ステップで巻き戻す
- `/effort` をClaudeの応答中にも実行できるよう改善（`/model` と同じ挙動）
- 高速なpush-to-talkの再押下時に一時的な接続失敗を自動リトライするよう音声モードを改善
- Remote Controlのspawnモード選択プロンプトのコンテキストを改善
- 起動時のIDE検出速度を改善
- macOSでのクリップボード画像ペーストの性能を改善

2.1.76
2026年3月14日

- MCP elicitationをサポート。MCPサーバーがタスクの途中で対話的ダイアログ（フォームフィールドまたはブラウザURL）を通じて構造化入力を要求できるようになった
  - MCP elicitation...MCPサーバーが処理の途中でユーザーに追加情報を入力してもらう仕組み
- 応答がサーバーへ返される前に介入・上書きできる `Elicitation` と `ElicitationResult` フックを追加
  - Elicitation...ユーザーに入力を求める前に発火するフック
  - ElicitationResult...ユーザーが入力をした後に発火するフック
- コンパクション完了後に発火する `PostCompact` フックを追加
- モデルのeffortレベルを設定する `/effort` スラッシュコマンドを追加
- 起動時にセッションの表示名を設定する `-n` / `--name <name>` CLIフラグを追加
- 大規模モノレポでの `claude --worktree` 向けに、git sparse-checkoutで必要なディレクトリのみをチェックアウトする `worktree.sparsePaths` 設定を追加
  - 裏でsparse-checkoutを使っている
  - sparse-checkoutはGitリポジトリの必要なファイルだけ作業ディレクトリに表示する仕組み
- セッション品質サーベイを追加。エンタープライズ管理者は `feedbackSurveyRate` 設定でサンプルレートを構成できる
- `--plugin-dir` をサブコマンド対応のため1パスのみ受け付けるよう変更。複数指定する場合は `--plugin-dir` を繰り返す
- `--worktree` の起動性能を改善。gitのrefを直接読み取り、リモートブランチがローカルで既に利用可能な場合は冗長な `git fetch` をスキップする
- バックグラウンドエージェントの挙動を改善。バックグラウンドエージェントを停止しても部分的な結果が会話コンテキストに保持される
- モデルのフォールバック通知を改善。verboseモードに隠れず常に表示され、人間が読みやすいモデル名を使用する
- ダークテーマのターミナルでのブロッククォートの可読性を改善（dimではなくイタリックと左バー）
- 古いworktreeのクリーンアップを改善。並列実行の中断後に残ったworktreeを自動的に削除する
- Remote Controlのセッションタイトルを改善。Interactive sessionではなく最初のプロンプトから生成する
- `/voice` を改善し、有効化時にディクテーション言語を表示。`language` 設定が音声入力で未サポートの場合は警告する
