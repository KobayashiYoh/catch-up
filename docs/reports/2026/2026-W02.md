# 2026-W02週次レポート（01/05〜01/11）

## キャッチアップ（AI）

2.1.2
2026年1月8日

- ターミナルにドラッグした画像に元のファイルパスのメタデータを追加
- OSC 8に対応したターミナル（iTermなど）で、ツール出力内のファイルパスをクリック可能なハイパーリンクとして表示
- Windows Package Manager（winget）によるインストールに対応し、自動検出と更新手順を案内
- Plan Modeで`Shift+Tab`を押して「編集を自動承認」オプションを選択できるようになった
- `FORCE_AUTOUPDATE_PLUGINS`環境変数を追加し、メインの自動更新機能を無効にしていてもPluginの自動更新を可能にした
- `SessionStart` Hookの入力に`agent_type`フィールドを追加。`--agent`が指定された場合にエージェント種別が設定されるようになった
- macOSでOptionキーをMetaキーとして使用する際の案内を改善し、iTerm2、Kitty、WezTermなどのCSIu対応ターミナルごとの手順を表示
- SSH経由で画像を貼り付ける際のエラーメッセージを改善し、クリップボードショートカットではなく`scp`を使用するよう案内
- 権限説明で`git fetch/rebase`、`npm install`、テスト、PRなどの日常的な開発ワークフローを中程度のリスクとして扱わないよう改善
- 大きなBashコマンドの出力を切り捨てずディスクに保存し、Claudeが完全な出力を読み取れるよう変更
- 大きなツール出力を切り捨てずディスクに保存し、ファイル参照経由で完全な出力を利用できるよう変更
- `/plugins`のInstalledタブでPluginとMCPをスコープ単位で統合して表示するよう変更
- Windowsの管理対象設定ファイルの推奨パスを`C:\ProgramData\ClaudeCode\managed-settings.json`から`C:\Program Files\ClaudeCode\managed-settings.json`へ変更
- [SDK] 最低`zod` peer dependencyを`^4.0.0`に変更

## 学んだこと

- OSC 8とは、ターミナル上にハイパーリンクを表示するための仕組み
- CSIuとは、キーボード入力を正確に伝えるための仕組み
- 到達不能なPermission Ruleを検出して警告するようになったことで、permissionの設定不備を検知してくれる
- `CLAUDE_CODE_TMPDIR`環境変数を設定しない場合、Claude Codeが内部一時ファイルに使用する一時ディレクトリはデフォルトで`tmp`
