# 2026-W30週次レポート（07/20〜07/26）

## キャッチアップ（AI）

2.1.216
2026年7月21日

- `sandbox.filesystem.disabled`設定を追加。ネットワークのegress制御は維持したままファイルシステム分離をスキップできる

---

2.1.217
2026年7月22日

- プロンプト入力に絵文字ショートコード補完を追加。`:heart:`と入力すると❤️を挿入し、`:hea`で候補が表示される。`emojiCompletionEnabled`設定で無効化できる
- トランスクリプトの書き込みが失敗している場合（ディスク満杯など）や、継承した環境変数によりセッション保存が無効化されている場合に警告を追加（従来はサイレントにトランスクリプトを失っていた）
- 同時実行サブエージェント数に上限を追加（デフォルト20、`CLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS`で変更可）。1つのメッセージからバックグラウンドエージェントが無制限にファンアウトしないようになった

---

2.1.219
2026年7月25日

- Claude Opus 5（`claude-opus-5`）を追加し、デフォルトのOpusモデルになった。1Mコンテキストを備え、fastモードは$10 / $50 per Mtok
- `sandbox.network.strictAllowlist`設定を追加。サンドボックス実行コマンドの非許可リストホストへの接続を、プロンプトなしで拒否できる
- `DirectoryAdded`フックを追加。`/add-dir`やSDKの`register_repo_root`コントロールリクエストでセッション途中に新しい作業ディレクトリが登録された後に発火する
- ヘッドレスのstream-jsonのinitイベントに`mcp_server_errors`を追加し、設定検証でスキップされた`--mcp-config`エントリを列挙するようになった。ターミナル実行では起動時警告を表示する
- `workflowSizeGuideline`設定キーを追加し、アドバイザリなDynamic workflow size guidelineを任意の設定ファイルから指定できるようになった。設定されている間は`/config`の該当行が非表示になる
- stream-jsonでのネストしたサブエージェント転送を追加。`--forward-subagent-text`設定時、depth-2以上で起動されたサブエージェントが、起動元Agentの`tool_use` idをキーとして表示される
