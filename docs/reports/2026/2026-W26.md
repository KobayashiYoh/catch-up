## 学んだこと

- `claude mcp login <name>`と`claude mcp logout <name>`により、対話不要でMCPサーバーのログイン・ログアウトができるようになった
- 通常のコマンドでも引数や組み合わせによっては危険な動作につながることがあるため、`autoMode.classifyAllShell`設定ですべてのBash / PowerShellコマンドをautoモードのclassifierに通せるようになった
- `autoMode.classifyAllShell`設定により、より広い範囲で実行内容を評価できるようになった
- autoモードの拒否理由が`/permissions`のrecent denialsに追加されたことで、Autoモードで最近拒否された操作とその理由を後から確認できる
- コンテナのプロビジョニングとは、コンテナを使える状況にするために必要な環境や設定を準備すること
- プロビジョニングチェックリストとは、Claude CodeのRemoteセッションを実行するための環境がどこまで進んでいるか確認するためのリスト
