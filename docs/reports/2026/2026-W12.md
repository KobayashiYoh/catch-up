# 2026-W12週次レポート（03/16〜03/22）

## キャッチアップ（AI）

2.1.77
2026年3月17日

- Claude Opus 4.6のデフォルト最大出力トークン上限を64kトークンへ引き上げ、Opus 4.6とSonnet 4.6モデルの上限を128kトークンへ引き上げ
- `denyRead` 領域内で読み取りを再許可する `allowRead` サンドボックスファイルシステム設定を追加
- `/copy` が任意のインデックスを受け付けるようになった。`/copy N` でN番目に新しいアシスタント応答をコピーする
- `/fork` を `/branch` へ改名（`/fork` はエイリアスとして引き続き動作）
- Agentツールが `resume` パラメータを受け付けなくなった。以前に起動したエージェントを継続する場合は `SendMessage({to: agentId})` を使用する
- `SendMessage` が停止中のエージェントをエラーではなくバックグラウンドで自動再開するようになった
- プラン承認時にプランの内容からセッション名を自動命名
- バックグラウンドのbashタスクは出力が5GBを超えると強制終了され、暴走プロセスによるディスク圧迫を防止する
- `apiKeyHelper` が10秒以上かかる場合に通知を表示し、メインループのブロックを防止
- `claude plugin validate` を改善し、skill/agent/commandのフロントマターと `hooks/hooks.json` を検証。YAMLのパースエラーやスキーマ違反を検出する
- ヘッドレスモードのプラグインインストールが `CLAUDE_CODE_PLUGIN_SEED_DIR` と正しく組み合わさるよう改善
- 実行中の非ストリーミングAPIリクエストをEscで中断できるよう改善
- macOSでキーチェーン認証情報の読み取りをモジュール読み込みと並列化し、起動を約60ms高速化
- フォークの多いセッションや非常に大きなセッションでの `--resume` を高速化。読み込みが最大45%高速になり、ピークメモリを約100〜150MB削減
- [VSCode] プランプレビューのタブタイトルをClaude's Planではなくプランの見出しを使うよう改善
- [VSCode] macOSでoption+clickがネイティブ選択を起動しない場合、フッターが `macOptionClickForcesSelection` 設定を案内するようになった

- 応答テキストが生成に合わせて1行ずつストリーミングされるようになった
- tmux内で `set -g allow-passthrough on` を設定している場合、ターミナル通知（iTerm2/Kitty/Ghosttyのポップアップ、プログレスバー）が外側のターミナルへ届くようになった
- 大きなセッションのresume時のメモリ使用量と起動時間を改善

2.1.81
2026年3月21日

- スクリプト用途の `-p` 呼び出し向けに `--bare` フラグを追加。フック、LSP、プラグイン同期、スキルディレクトリ探索をスキップする。`ANTHROPIC_API_KEY` または `--settings` 経由の `apiKeyHelper` が必要（OAuthとキーチェーン認証は無効化）。auto-memoryも完全に無効化される

- worktree内にあったセッションをresumeすると、そのworktreeへ戻るようになった
- MCP OAuthを更新し、Dynamic Client Registrationに非対応のサーバー向けにClient ID Metadata Document（CIMD / SEP-991）をサポート
- プランモードでデフォルトではclear contextオプションを非表示に変更（`"showClearContextOnPlanAccept": true` で復元）
- レンダリングの問題により、Windows（Windows Terminal上のWSLを含む）で1行ずつの応答ストリーミングを無効化
- MCPのread/searchツール呼び出しを単一のQueried {server}行へ折りたたむよう改善（Ctrl+Oで展開）
- `!` bashモードの発見性を改善。対話的コマンドを実行する必要がある場合にClaudeが提案する
- プラグインの鮮度を改善。ref追跡型プラグインは毎回のロード時に再クローンして上流の変更を取り込む
- Remote Controlのセッションタイトルを3通目のメッセージ後に更新するよう改善

## 学んだこと

- macOSはOption + クリックで範囲選択をするようになっている
- `StopFailure`フックにより、APIエラーでターンが終了した際にログを残したり、通知したりできる
- VS Codeの`/remote-control`でMac側に表示された接続情報をもとに、スマホのブラウザでClaudeにログインするとスマホからセッションを開くことができる
- VS Codeの`/remote-control`で接続したスマホからは、操作も可能だが、編集のプレビューなどは見ることができない
- `--channels`は、CIなどの外部イベントをClaude Codeへプッシュする仕組み
- `--bare`フラグは、余計なClaude Code機能を無効化する
