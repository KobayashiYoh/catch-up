# 2026-W35週次レポート（08/24〜08/30）

## キャッチアップ（AI）

2.1.243
2026年8月25日

- `/usage` にLoopsの内訳を追加。ループごとの実行回数、合計トークン、実行あたりトークン、最終実行時刻を表示し、暴走・冗長な `/loop` タスクを見つけやすくなった
- `modelPicker` 設定を追加。順序付き・ラベル付きのモデルリストで `/model` ピッカーをキュレーションでき（Vertex / BedrockのID表記を含む任意のID表記に対応）、組み込みラインナップへの追加または置き換えができる
- `promptCacheTtl` と `subagentPromptCacheTtl` 設定を追加。APIキー利用者やクラウドプロバイダ利用者が、メイン会話は1時間のプロンプトキャッシュを保ちつつサブエージェントは5分のままにできる
- `modelPricing` マネージド設定を追加。組織の契約モデル単価と割引率を `/cost`、ステータスライン、テレメトリのコスト表示に定価の代わりに使用
- `/login` → Anthropic Consoleにキーレスサインイン「Sign in with your Console account」（推奨）をAPIキー作成と並んで追加。APIキーを許可しない組織でもサインイン可能に
- `/status` に `Skipped sources` 行を追加。より優先度の高いマネージドソースが有効なため適用されていないマネージド設定ソース（`managed-settings.json` など）を一覧表示
- Claude Code on the web向けにGitHubが接続済みかを示す `/status` 行を追加（Pro / Max）。未接続時は `/web-setup` を案内
- 各サブエージェントが実行されたモデル（およびエフォートレベル）を `/tasks` とエージェント詳細ダイアログに表示するようになった

2.1.248
2026年8月28日

- `--restricted`（または `CLAUDE_CODE_RESTRICTED=1`）を追加。コマンドやコードを実行する組み込みツールと `WebFetch`（`--tools` で明示しない限り）を除去し、ファイルツールは作業ディレクトリ内に限定、`bypassPermissions` を拒否、ユーザー・プロジェクト・ローカルの設定ファイルを無視する
- エージェントfrontmatterに `experimental.cacheTtl`（`"5m"` または `"1h"`）を追加。サブエージェントTTL設定が無い場合に使われるエージェント単位のプロンプトキャッシュTTL
- `claude self-hosted-runner --client-label <label>`（または `SELF_HOSTED_RUNNER_CLIENT_LABEL`）を追加し、ランナーが登録するラベル（デフォルトはホスト名）を上書き可能に
- サーバーマネージド設定の診断を追加。読み込み失敗時の起動警告と、失敗理由や取得されなかった理由（Bedrock / Vertex / サードパーティプロバイダ、カスタム `ANTHROPIC_BASE_URL`）を説明する `/doctor` と `/status` の行
- GitHub CLIのトークンに `workflow` スコープが無い場合の警告を `/web-setup` に追加（非常に大きなリポジトリへのpushが拒否されうるため）
- AWS Marketplace経由請求、セルフサーブEnterprise、Enterpriseトライアルの組織向けに `/usage-credits` を追加し、メンバーが管理者に使用上限の引き上げを申請できるようになった
- 同一マシン上のセッション間メッセージング（`SendMessage` / `ListAgents`）を、Bedrock / Vertex / Foundryおよびテレメトリ無効時にも提供
- `/loop` を変更。self-pacedなdynamicモードと、プロンプト無しのautonomousデフォルトをBedrock / Vertex / Foundryを含め常時利用可能にした

2.1.251
2026年8月29日

- `PreModelSwitch` / `PostModelSwitch` フックイベントを追加（モデル切り替えのブロック・確認・注釈が可能）。`SessionStart` のresumeフックはセッションの古さと再キャッシュ推定コストを受け取るようになった

- 支出上限付きClaude apps gatewayの背後にいる開発者向けに、`/usage` のSpend limitバーと `rate_limits.spend_limit` ステータスラインフィールドを追加
- `/cost` にセッション単位のプロンプトキャッシュ行（ヒット率、ミス数、再キャッシュされたトークン、warm/cold）と、ステータスラインスクリプト用の `prompt_cache` オブジェクトを追加
- `claude --help` に `attach`、`logs`、`stop`、`respawn`、`rm` を追加。実行中バックグラウンドセッションに対する `--resume` のメッセージが正確な `claude attach <id>` コマンドを表示するようになった
- `/radio` をBedrock / Vertex AI / Foundry / Claude Platform on AWS、およびテレメトリ無効時にも利用可能にした
