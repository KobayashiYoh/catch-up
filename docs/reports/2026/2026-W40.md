# 2026-W40週次レポート（09/28〜10/04）

## キャッチアップ（AI）

2.1.284
2026年9月29日

- Claude Sonnet 5.5（`claude-sonnet-5-5`）を追加し、Anthropic APIのデフォルトのSonnetモデルになった。1Mコンテキスト、$2/$10 per Mtok、キャッシュ読み取り$0.20/Mtok
- autoモードの作業ディレクトリ外の読み取り前のプロンプトに「Yes, but ask again next time」の回答を追加し、その1回だけ許可しつつ以降の読み取りでは引き続き確認を受けられるようになった
- Claude apps gatewayの支出上限に、`/usage` とステータスラインでのドル金額表示を追加（例: 「$271.40 / $500.00 spent this month」。ゲートウェイが本バージョン以降の場合）。ステータスラインの `rate_limits.spend_limit` に `used_usd`、`limit_usd`、`period` も追加
- `effortSlider:decreaseEffort`、`increaseEffort`、`toggleUltracode` のキーバインドアクションを追加し、`/effort` スライダーの矢印キーとTabキーを `keybindings.json` で再割り当て可能に
- claude.aiサブスクライバー向けに `/rate-limit-options` を `/help` とコマンドメニューに追加。利用上限の通知が案内するコマンドを見つけられるようになった
- インタラクティブターミナルで `/mcp reconnect all` を追加し、接続に失敗した、または認証が必要なMCPサーバーをまとめて再試行可能に
- マネージドポリシーの `availableModels` が空の場合、またはClaude Codeの起動モデルを除外していて `model` や `enforceAvailableModels` が未設定の場合に、Claude apps gatewayの起動時警告を追加
- Claude apps gatewayの `telemetry.forward_to` の送信先に `auth: { google: {} }` を追加し、ゲートウェイのGoogle Cloud認証情報でGoogle CloudのOTLPエンドポイントへ直接テレメトリをエクスポート可能に
- Claude apps gatewayとIDP間の証明書クライアント認証（`private_key_jwt`）を追加。クライアントシークレットの代わりに証明書の認証情報を発行するIDP向け
- [VSCode] 各プロンプトと応答の上に表示する時刻と、日付が変わる箇所の日付行を追加（Claude Code: Show Message Timestamps設定。デフォルトはオフ）
- [VSCode] Manage pluginsの行にプラグインの読み込みエラーとメモを追加し、無効化・アンインストール・エラーのコピーができるポップアップを追加
- [VSCode] EffortスライダーのUltracodeのON/OFFスイッチを追加し、スライダーのUltracodeストップに代わるものとした。モデルピルには任意のエフォートレベルで「· Ultracode」が表示される
- [Claude Tag] スレッド、チャンネルのデフォルト、DMに「Opus (latest)」のようなモデルファミリーの選択肢を追加し、そのファミリーの最新モデルに追従するようになった
- [Claude Tag] 組織全体の上限に計上される支出を、分析の支出予測チャートに追加し、上限の使用状況も表示

2.1.285
2026年9月30日

- `CLAUDE_CODE_DISABLE_WEB_FETCH` 環境変数を追加し、WebFetchツールを無効化可能に
- `claude --desktop` を追加。現在のディレクトリ、または `--continue` / `--resume <id>` 併用時のセッションでClaudeデスクトップアプリを開く
- `claude plugin configure <plugin>` を追加。プラグインのオプションと未設定のものを表示し、`--values-stdin` で標準入力から読み取った新しい値を保存可能
- `claude plugin install --config` に `<server>.<key>=<value>` を追加し、同梱の `.mcpb` MCPサーバー自身の設定をインストール時に指定できるようになった。`/plugin` → Configureを経由せずに起動する
- `allowedProviders` マネージド設定を追加し、マシンで使用可能なAPIプロバイダ（Anthropic API、カスタムエンドポイント、Bedrock、Mantle、Vertex AI、Foundry、Claude Platform on AWS、Cloud gateway）を制限可能に
- `CLAUDE_CODE_NONSTREAMING_TIMEOUT_RETRIES` 環境変数を追加し、タイムアウトした非ストリーミングフォールバックリクエストの再送回数に上限を設定可能に
- [VSCode] ウィンドウのリロードで中断された、復元タブの最後のメッセージの下に、返信が来ない旨の注記を追加
- [VSCode] Manage pluginsにプラグインのオプションフォームを追加。オプションを持つプラグインのインストール時に未設定のものを尋ね、行の歯車アイコンで後から変更可能
- [VSCode] パネル内のClaudeが、ファイル編集直後だけでなくいつでもProblemsパネルの現在のエラーと警告を読めるオンデマンドの診断ツールを追加
- [Claude Tag] Cowork利用者のうちEnterpriseプランのStandardまたはUsage-Based Chatシートを持つメンバー向けに、Claudeとのダイレクトメッセージを追加。Claude Codeを含むシートは不要になった
