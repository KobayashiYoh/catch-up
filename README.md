# Catch Up

## 概要

日々の情報収集用リポジトリ。

主に「AI」と「モバイルアプリ開発」の2軸をメインとし、定期的に情報収集する。
AIは、特にClaude Codeに関する情報を中心に情報収集する。
モバイルアプリ開発は、Flutterに加え、AndroidとiOSの情報を中心に情報収集する。

## 目的

- 進化のスピードが激しい技術分野において、最新の情報を追い続けるため
- 情報のキャッチアップを習慣化するため
- 身につけた技術を実際のプロジェクトに活かすため

## レポート

- 週ごとにキャッチアップのレポートを作成する
- 週はISO週番号で運用する
